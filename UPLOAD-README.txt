支线说明与上传步骤
这是给现有 Twopopos/pixel-english-quest 仓库使用的更新包。

上传方法
1. 先解压 ZIP。不要直接把 ZIP 作为网页文件上传。
2. 把包内全部文件上传到原仓库根目录，与原 index.html 同级；不要放进额外的子文件夹。
3. 用新 index.html 覆盖旧文件。quest-game.html、所有 display 开头的文件、station 开头的文件和两个 TTF 字体都必须一起上传；不要只替换 index.html。
4. 原有 quest-home.webp、quest-completion.webp、quest-horizon.webp 和三个 quest-journey-*.mp3 音乐文件继续保留，原 PDF 文件也保留。
5. Commit changes 后等待 GitHub Pages 部署完成，再刷新网页。若仍显示旧版，关闭旧标签页后重新打开。

如何进入
完成第三关后，结尾画面顶部新增 OWL POST · PLATFORM 9¾ 入口。
原探索模式的顶部工具栏也会显示此入口。
解锁后，该浏览器会记住入口资格；前三关进行中不会出现入口。
退出支线会回到进入前的主游戏位置，不会重置原关卡。
也可以在现有网站路径末尾使用 station.html 单独试玩支线；独立打开时，单词和剧情保存在支线背包中，主游戏旅行手册的同步需要通过主游戏入口进入后产生交互。

支线内容
- 9¾ 红砖入口、猫头鹰邮袋、蒸汽夜车、会眨眼的画像、漂浮蜡烛。
- 向站长领取信件，在背包中取得 Grow / Float / Reflect 三张单词卡。
- Grow 藤蔓攀爬与高架路线，Float 木箱浮筏与水上路线；可探索两条路线。
- Reflect 反射光束，并转动镜面点亮观测室灯笼，开启拱门。
- 向 Rowan 送信，带回回信，乘夜车回站；交还后车站灯光发生变化。
- 上层路线可找到猫头鹰羽毛纪念物。
- 每次场景切换约 3 秒；遵循浏览器减少动态效果设置。
- 支线使用独立本地存档；每 5 秒、重要交互、页面切换时保存。
- 原背景音乐继续使用 YannZ 的 Asami’s Journey 音轨，保留音乐署名；新增魔法音效由程序合成。

操作
A / D 或 ← / →：移动。
W / ↑ / SPACE：跳跃；在藤蔓旁按住可以攀爬。
S / SHIFT / ↓：从高架路线下穿。
E / ENTER：与附近场景交互。J：查看支线背包。
手机使用固定的方向、下穿、跳跃按钮，中央交互按钮按需出现。
RETURN：退出支线。BACK TO SAFE GROUND：保留物品，返回本区域入口。
