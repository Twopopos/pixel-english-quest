上传方式：解压整合包，将解压后的全部文件及 assets 文件夹按原结构上传到 GitHub Pages 的发布目录（通常是 main 分支根目录）。不要只上传 index.html，也不要把 ZIP 本身作为网站。
index.html 必须位于发布目录根目录。assets/Climbing_the_Career_Ladder.pdf 为正式课件，不能遗漏。

本版：New Game 前为一关向上攀登；高处终点自动开门，3 秒登阶后自动显示 7 页正式课件；完成探索后进入原结尾。电脑游玩自动填满窗口，可点击 FULLSCREEN 尝试原生全屏。New Game、车站支线、旅行手册、音乐和结尾保留。

正式 PDF 随网站发布，其他电脑打开网址即可读取，首次使用需要联网。无需在每台电脑导入或保存。旧浏览器存储不会自动覆盖正式课件。添加并保存的临时课件只影响当前浏览器，可用“恢复默认课件”切回正式 PDF。原有课件记录不删除。

如果仍见旧版，确认 GitHub Pages 的最新部署完成后刷新，页面版本标记应为 V14.0 · ONE CLIMB。
PPT 转 PDF 后不含动画与视频播放，缺失字体使用相近字体替代，7 页文字与图片顺序保留。公开网站中的 PDF 可被访问和下载。

所有单文件小于 25 MiB。上传时保留 assets 文件夹；没有需要安装的依赖。测试详情见 TEST-REPORT.txt。
