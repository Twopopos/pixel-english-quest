如何找到车站
首次游玩：完成前三关 → 来信提示 → VISIT PLATFORM 9¾。
已经解锁：从首页或结尾的信封卡片进入，或从自由探索顶部“车站支线”进入。
站内流程：站长领取信件 → 右侧行李处领取单词卡 → 继续右行到标着 9¾ 的红砖入口。
原有浏览器中的已解锁状态会保留；清除网站数据或换浏览器不会同步本地存档。

操作与支线内容
A / D / ← / → 移动；W / ↑ / SPACE 跳跃，藤蔓旁按住攀爬；S / SHIFT / ↓ 下穿。
E / ENTER 场景交互，J 查看背包。手机保留原方向、下穿、跳跃按钮和按需出现的交互键。
Grow 让藤蔓生长，Float 让木箱漂浮，Reflect 使镜子反射光线；再转动镜面点亮灯笼。
送信给 Rowan，乘夜车带回回信，交还站长。支线自动保存，可退出回到主游戏原位置。
音乐继续使用 YannZ 的 Asami’s Journey 音轨；站内保留署名。
